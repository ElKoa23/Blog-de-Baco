# 🍷 Baco — Blog sobre el mundo del vino

**Historias, cepas, destinos y experiencias para brindar.**

Baco es una web dedicada a compartir contenido sobre la cultura del vino. A través de artículos, imágenes y consejos, invita a descubrir cómo catar un vino, conocer viñedos y encontrar combinaciones entre vinos y comidas.

El proyecto reúne páginas creadas con HTML, CSS y Bootstrap, con una identidad visual inspirada en los tonos del vino y un diseño pensado para distintos tamaños de pantalla.

## ¿Qué podés encontrar en Baco?

- **Inicio:** presentación del blog, carrusel de imágenes y últimas entradas.
- **Artículos:** contenido sobre cata de vinos, viñedos de Cafayate y maridaje.
- **Galería:** selección de imágenes relacionadas con vinos y bodegas.
- **Contacto:** formulario y ubicación.
- **Acceso:** pantallas de inicio de sesión y recuperación de contraseña.
- **Página 404:** diseño de página no encontrada con un enlace para volver al inicio.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS:** estilos propios, colores y ajustes para distintas pantallas.
- **Bootstrap 5:** grilla, componentes y comportamiento del carrusel.
- **Bootstrap Icons:** iconos utilizados en las entradas del blog.
- **Git y GitHub:** control de versiones y colaboración.
